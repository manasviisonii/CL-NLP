## About the Assignment

This repository contains the solved LSTM practice assignment for the Computational Linguistics and Natural Language Processing course.

The assignment covers numerical problems, LSTM operations, gradient flow, and real-world applications of LSTM networks.

## Questions Covered

### Question 1: LSTM Forward Pass
- Calculation of forget, input, and output gates.
- Candidate cell state calculation.
- Updated cell state and hidden state computation.

### Question 2: LSTM Parameter Count
- Parameter calculation using the standard single-bias convention.
- Parameter calculation using PyTorch's two-bias convention.

### Question 3: Vanishing Gradient
- Gradient scaling across multiple time steps.
- Effect of forget-gate values on gradient flow.
- Comparison between LSTM and vanilla RNN.

### Question 4: Electricity Load Forecasting
- Dataset size calculation.
- Sliding-window generation.
- Input and output tensor shapes.
- Training batches and LSTM parameter count.

### Question 5: Predictive Maintenance
- Min-max normalization.
- Failure prediction using probability thresholds.
- Confusion matrix calculation.
- Precision, recall, F1-score, and accuracy.
- Evaluation metric selection.
